#**STUDENT PERFORMANCE ANALYSIS USING EXCEL, SQL AND POWER BI**



**Project Overview**

This project explores student academic performance using the UCI Student Performance dataset. The goal was to analyse final grades, examine pass rates, compare school performance and present findings through interactive dashboards.



**Dataset**

\- Source: UCI Student Performance Dataset

\- Records: 395 students

\- Main performance variable: G3 (final grade out of 20)



**Tools Used**

\- Microsoft Excel

\- MySQL

\- Power BI

\- DAX



**Project Process**

1\. Excel

\- Explored and analysed the dataset.

\- Created PivotTables and calculated KPIs.

\- Developed an interactive dashboard.



2\. SQL

\- Queried and filtered student records.

\- Used aggregate functions and conditional statements.

\- Analysed pass rates and performance levels.

\- Compared average grades across schools.

\- Validated pass-status records.



3\. Power BI

\- Created DAX measures.

\- Developed KPI cards and visualisations.

\- Built an interactive dashboard with slicers.



**Key Findings**

\- Total students: 395

\- Average final grade: 10.42/20

\- Students passing: 265

\- Pass rate: 67.09%

\- GP average grade: 10.49

\- MS average grade: 9.85
